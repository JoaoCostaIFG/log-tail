An IPv6 address is 128 bits long, written as 8 hexadecimal groups of 16bits. The :: shorthand replaces a run of zeros . The shortest addresses are therefore those where only the first group is non-zero: X:: . Only the global unicast block 2000::/3 is actually usable.
