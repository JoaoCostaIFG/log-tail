The Web-based Correctness-by-Construction (CbC) IDE WebCorC is a modern, web-based evolution of the Eclipse-based CorC tool. It provides a graphical and textual Integrated Development Environment (IDE) designed to support the Correctness-by-Construction (CbC) approach to software development. Correctness-by-Construction is a methodology where programs are developed incrementally, guided by rigorous pre- and post-condition specifications. Instead of writing code and then testing it, developers use refinement rules that guarantee the correctness of the implementation at every step.
