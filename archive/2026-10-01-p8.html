Dragomand is a per-user Linux daemon that gives desktop applications fully offline machine translation over D-Bus. It runs Mozilla's Bergamot/Marian translation models locally, the ones behind Firefox Translations, and manages which models are installed and which stay loaded in memory. The first call downloads the model from Mozilla (verified by SHA-256) and starts the daemon through D-Bus activation. Everything afterwards is fully offline, and the daemon exits again when idle. The existing Linux options are either standalone applications or translation tied to a single host such as Firefox.
