Ultra-portable · Embeddable · Statically typed Kio is a statically typed, embeddable programming language. Write a package once, then transpile it to the host language or load it dynamically into the host of your choice. One package compiles to 8 host languages. Kio emits code in the host's own language — no separate runtime to ship. Kio packages are components, not standalone programs. The host supplies the package's capabilities and decides which exposed entries to call. Kio is statically typed, including its declared host interfaces. Host implementations must honor those interfaces. A package declares its build targets, and Kio emits idiomatic code for each one.
