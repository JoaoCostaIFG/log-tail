The Benchmarking Crisis

L 1 points · by timschumi · databasearchitects.blogspot.com · discuss

Goodhart’s law , that any measurable target stops being useful when people start optimizing for it, very much holds in database benchmarking. That is not new, of course. Famously, TPC-D got retired when people optimized so much for it that the query runtimes converged towards zero due to excessive caching. TPC-H fixed that by declaring itself to be an ad-hoc benchmark, and explicitly forbidding things like exploiting knowledge about the workload or caching results (and a number of other optimizations). We now see the same problem with the ClickBench benchmark, heavily accelerated by today’s use of AI code generation.
