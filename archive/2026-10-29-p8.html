Show HN: Nouli – A multi-turn decision graph harness for System One models

HN 4 points · by SurfingAlpaca · github.com · discuss

Nouli is a multi-turn decision harness: it runs decision models over many turns. A decision model doesn't write text. You give it facts and a question with a fixed set of answers, and it returns a probability for each answer. That makes it useful for real decisions, but each call is stateless: the model forgets everything once it answers. Nouli gives it a memory. A session keeps every fact, question, and answer, so when something changes you add only what is new, and the model decides again with the whole history in view. Nouli ships as a CLI and a Rust library. On Linux , or on macOS without Homebrew: The script installs into ~/.local/bin after checking the download's checksum.
