The goal is to detect whether the compilation target (instruction set architecture or ISA to be precise) supports certain features that the compiler is allowed to use, such as instructions or registers. Typically this is done to use the appropriate, often more performant, implementation, or to verify if the program is compatible with the target at all. This doesn't actually involve detecting CPU features directly but rather exposes properties of the compiler's current target, either as specified or detected based on the CPU the compiler is run on, when built with -march=native or equivalent.
