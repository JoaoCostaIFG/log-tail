Evergreen: A Provably Safe Systems Language

HN 56 points · by jordan_bonecut · evergreenlang.net · discuss

Evergreen brings explicit contracts, checked invariants, and control over memory into one language. Write down what must hold. Let the compiler check that it does. The constructor requires a nonzero input. The compiler checks the invariant when the value is built. Put preconditions, postconditions, and data invariants beside the code they describe. They become obligations the compiler checks. Work with explicit layouts, ownership, and borrowed references. Evergreen tracks when a memory plane is live and which uses remain valid. Proofs, lemmas by induction, and ideal computations are erased after checking. Executable code keeps the work it needs to do. External console behavior is provided by the host. Evergreen records this boundary as an explicit trustme assumption.
