The Hypertext Transfer Protocol Status Code 483 (I'm Not a Freezer)

HN 53 points · by rbanffy · datatracker.ietf.org · discuss

This document defines the Hypertext Transfer Protocol status code 483 (I'm Not a Freezer). A server returns this status code when it understands a request that requires freezing or refrigeration capabilities but is not capable of providing those capabilities. This document also clarifies the distinction between a freezer, a refrigerator, a server operating at a low temperature, a frozen software process, and an online service advertising "cold storage".
