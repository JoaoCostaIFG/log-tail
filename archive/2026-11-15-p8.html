Show HN: Hazel – Declarative schema management for SQLite

HN 3 points · by winebarrel · github.com · discuss

hazel is a declarative schema management tool for SQLite. It reads the desired schema from SQL files and generates the DDL that brings a database in line with it. The schema files are run in an in-memory database and read back from sqlite_schema and the schema PRAGMAs, the same way the target database is read. The two schemas are compared, and the difference becomes ALTER TABLE where SQLite supports the change, or a rebuild of the table, which runs only when it is allowed. Expressions and views are compared by the bytecode SQLite compiles them to. Release binaries and Linux packages are on the releases page. See Installation .
