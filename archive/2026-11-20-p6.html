I’m pleased to announce a new source control tool, jj-musubi , that live-syncs copies of a Jujutsu ( jj ) repository across multiple machines. Every time jj snapshots my work, jj-musubi syncs it to every machine in moments, and also commits, rebases, fetches, and so on. This simple capability is surprisingly powerful. jj-musubi makes repos on multiple machines feel like jj workspaces (worktrees if you speak git). It’s intended for use by one person who works across several machines, so it has no security model (or rather, that is the extent of its security model). Jujutsu already treats the working copy as a commit. Running jj status records a snapshot of my edits in that commit, which jj-musubi then syncs to my other machines.
