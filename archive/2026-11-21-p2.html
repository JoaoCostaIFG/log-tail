Each comparator*.json pairs a statement file with Solution.lean , names the theorems whose statements must agree, and permits only the axioms propext , Quot.sound and Classical.choice . The library is large (about 2,270 files and 600,000 lines), and a full build needs a great deal of memory and time. The formalization contains no data.
