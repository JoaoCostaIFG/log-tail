Why do we use automated testing when building software? We test because we want to find issues internally and not have them be found for us by users (who may not even report them at all). We do this reactively ; when an implementation bug is found, a failing test we think corresponds to the bug is written, and the system is changed to make the test pass. If the bug can no longer be reproduced, we have proven to ourselves that the test corresponds to the bug, and we keep the test to guard against further regressions.
