Show HN: Katamaran - Open-source Docker and Linux runtime for Apple Silicon

HN 5 points · by nklmilojevic · katamaran.rs · discuss

katamaran pairs a custom Hypervisor.framework virtual machine monitor (based on libkrun) with a native Swift and AppKit macOS app and the kat command-line tool. Shared folders run through a macOS virtio-fs server with direct hypercalls and FSEvents cache invalidation. Networking runs in-process with gvproxy, and unused guest memory returns to macOS in 64 KiB blocks. katamaran requires an Apple silicon Mac (M1 or later) running macOS 15 or later. It does not include Kubernetes.
