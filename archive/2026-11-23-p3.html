Elixir HLS makes FPGA circuits from functions written in Elixir

HN 138 points · by kristianpaul · github.com · discuss

Elixir HLS makes FPGA circuits from functions written in Elixir: high-level synthesis (HLS). FPGA circuits are usually written in a hardware description language such as Verilog or VHDL, register by register: which value goes into which register at which clock. This is called RTL (register transfer level). High-level synthesis generates that RTL from code in a software language: the author says what to compute, and the tool decides the clocks and the registers. In Elixir HLS that language is Elixir. A function defined with defhls stays an ordinary Elixir function that runs on the CPU, and also becomes an FPGA circuit.
